# CustomEncryptDecrypt
Custom encryption-decryption tool in python.Simple to make.
Install instructions:
Windows:

git clone https://github.com/filipgg718-ship-it/CustomEncryptDecrypt.git
cd CustomEncryptDecrypt
python cipher.py



Linux(deb):

sudo apt update
sudo apt install git python3 -y
git clone https://github.com/filipgg718-ship-it/CustomEncryptDecrypt.git
cd CustomEncryptDecrypt
python3 cipher.py



MacOS:


xcode-select --install

git clone https://github.com/filipgg718-ship-it/CustomEncryptDecrypt.git
cd CustomEncryptDecrypt
python3 cipher.py



If you don't have python 3 installed use https://www.python.org/downloads/  to install it.
